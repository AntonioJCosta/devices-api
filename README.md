# Devices API

REST API com Bun + Elysia + Drizzle ORM + PostgreSQL

## Scripts

```bash
bun run src/index.ts      # Inicia o servidor local
docker-compose up         # Sobe API + DB com Docker
```

## Estrutura

- API REST com validações
- Persistência com PostgreSQL
- Schema com Drizzle ORM
- Containerizado com Docker
